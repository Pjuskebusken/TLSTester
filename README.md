# TLSTester
Small tool for scanning TLS version of a website using OpenSSL installed from Git.

Can be run either running the TLSTester.ps1 directly from the terminal or by double clicking the .bat file.

Requirements: **Git**

<ins>**Only works on Windows**</ins>

## How to run

Download the files by click on the green "<> Code" button in the top right.  
Extract the files  
Run the TLSTester.bat file  

Or you can just clone the repository, but then I assume you know what you're doing :^)
